# Unyeon

**운연역 반경 10km 인구·가구·이동 지도** — 인천 2호선 운연역(인천 남동구)을 중심으로 반경 10km 안 행정동 131곳의 인구구조·가구원수·1인가구(왼쪽 패널 탭)와, 반경에 걸친 시군구의 연령별 전입·전출·순이동(오른쪽 지도)을 보여줍니다.

- 지도: [index.html](index.html) (탭 바로가기 `#hh` 가구원수, `#one` 1인가구)
- 왼쪽 탭: **인구구조**(2026.10 주민등록, 5세 구간 피라미드·시군구별·행정동 표) · **가구원수**(2025 인구총조사 일반가구 1~6인 이상) · **1인가구**(시군구·행정동 비율, 분포)
- 오른쪽 지도: 시군구 영역을 순이동/전입/전출로 색칠하고, 시군구 카드에 연령별 막대. 아래 패널은 시군구 × 연령 순이동 히트맵, 시군구를 누르면 연령별 전입·전출·순이동 상세.
- 카드·히트맵은 **연령별 / 전입사유별**(직업·가족·주택·교육·주거환경·자연환경·기타) 전환
- **화살표**: 기본은 8개 시군구 사이 쌍별 순이동(100명 이상, 굵기=인원), 시군구를 누르면 오고 간 인원 상위 10개 상대 지역과의 전입(파랑)·전출(빨강)
- 행정동을 누르면 패널 위에 그 동의 피라미드와 가구원수

## 방법과 한계
- 행정동 경계의 넓이 중심점이 운연역에서 10km 안인 동만 넣었습니다. 경계만 원에 걸친 32개 동은 빠졌고, 넣은 동은 원 밖 부분까지 동 전체 인구를 셉니다.
- 연령은 원표의 5세 구간 그대로이며, ‘65세 이상’처럼 원표에 없는 구간은 합산해 만들지 않았습니다.
- 가구는 인구총조사(2025.11.1 기준) 일반가구로 주민등록 세대와 다릅니다. 서해구 가좌2·3·4동은 조사 당시 인천 서구 코드로 연결했습니다.
- 읍면동 단위 연령별 이동 통계가 KOSIS에 없어 이동은 시군구 단위입니다.
- 반경·시군구 합계는 행정동 값을 더한 직접 집계입니다(공식 집계 단위가 아님).
- 받은 값은 동마다 5세 구간 합 = ‘계’, 남+여 = 총인구로 검증했습니다.

## 다시 만들기
```
node scripts/select_dongs.mjs         # 브이월드로 역 좌표 → 반경 10km 행정동 선택 (V-WORLD_KEY)
node scripts/download_population.mjs  # KOSIS OpenAPI로 5세별·성별 인구 (KOSIS_..._KEY)
node scripts/download_households.mjs  # 인구총조사 가구원수별 가구
node scripts/download_migration.mjs   # 시군구 연령별 전입·전출·순이동
node scripts/download_flows.mjs       # 전입사유별 이동 + 시군구 간 이동(화살표)
node scripts/build_data.mjs           # 지도용 data/unyeon_data.js
python -m http.server 8000
```
키는 상위 폴더 `.env`에 두며, 웹 페이지에는 어떤 키도 들어가지 않습니다.
